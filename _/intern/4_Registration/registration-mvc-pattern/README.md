Сервис "Регистратор"

"Регистратор" — это сервис для регистрации и проверки данных о физических лицах, включая сохранение паспортных данных и связанных медиафайлов. Сервис предоставляет возможности для управления записями пользователей, отслеживания логов активности и работы со справочными данными.

Технологический стек

Backend: Spring Java

Frontend: Vue JS

База данных: Postgres
